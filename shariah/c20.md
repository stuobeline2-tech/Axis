# Shariah analysis — c20 Data annotation platforms (Outlier, DataAnnotation, Surge, Appen)
**Verdict: EXCLUDED — but on §2.4 platform terms, not on Shariah. Shariah certainty 9/10.**
The work itself (labelling and evaluating model outputs for a fee) is clean: defined task, defined
pay, no riba, no maysir, no deception. It is excluded because the platforms' terms prohibit AI
assistance and automation, and enforce that with bans (`research/evidence/c20.md`). Using an AI
agent to perform work on a platform that forbids it is deception of the counterparty — so the
platform rule and the Shariah rule point the same way here. **Permanently out of scope, not
"carefully" in scope.**
