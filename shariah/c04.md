# Shariah analysis — c04 Excel / VBA automation for SMEs
**Verdict: PASSES. Certainty 9/10.**
1. Sold: a working spreadsheet tool or macro. Consideration: flat fee per project. 2. **Gharar:**
low if the spec is written before work starts; "make my spreadsheet better" is not a spec.
3. **Riba:** none. 4. **Maysir:** none. 5. **Rights:** client's data and files; any library or
template reused must be licensed for commercial use. 6. **Claims:** no overstated time savings.
7. **Harm:** low; the one real risk is building a tool whose output the client will rely on for
financial decisions without validation — so the deliverable includes checks and stated limits.
8. **Customer revenue:** varies; screen individually and decline gambling, alcohol, adult, lending.
