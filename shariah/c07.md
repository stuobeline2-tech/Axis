# Shariah analysis — c07 Data quality remediation / migration cleanup
**Verdict: PASSES. Certainty 9/10.** Flat or per-record fee for defined cleansing work; no riba,
no maysir. **Gharar** removed by defining record count, rule set and acceptance test up front.
**Rights:** the data is the client's, handled under a processor instruction with deletion at end of
engagement; if the records are personal data, a DPA is required before any file is accepted.
**Harm:** incorrect merge/dedup decisions can destroy real records — so the deliverable is
reversible (never destructive in place) and ships with an exception report. **Customer revenue:**
screen individually.
